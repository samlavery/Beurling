1. [FIXABLE - most substantive] A-rankfull.tex:242-251, 269-279, 196-203, 382; v3 2696-2699, 2704.
   The Euler-chain bookkeeping in (S3) and in the Pivot-Integration Lemma (PIL) is incomplete.
   (a) Eu_s(s) is defined over "slot <= s", so it includes the pivot itself. But l.272 says the carried factor 1/Eu_s(s_p) "involves only primes of slot < s_p".
   (b) At the first block of each chain, Eu_s(top) is not F_{s_{p_{t+1}}-}-measurable, and no carried factor cancels it. The scheme only handles the bottoms of the chains.
   (c) The step "Eu(top+H)/Eu(bottom-H) <= ... by Lemma cm(iv) on Good" needs Good up to top+H, but at that point only G_{<s_top} is carried.
   (d) The PIL label sum Sum_s 1(q in W_s)/H(s) (l.200) treats Psi as independent of s. In fact the carried 1/Eu_s(s) and the block range both depend on s. Bounding that dependence pivot by pivot costs about e^{2k^2 H(X0)/X0}, which is not small for k >~ (X0/H)^{1/2}.
   Fix:
   - Sum the block below each pivot inside the conditional expectation at s_p, so that Eu_s(s) cancels before the label sum.
   - Define Eu_s over slots < s.
   - At each chain top, replace Eu_s(top) by the sure bound valid on G_{<s_top}, as in the second branch of (F3'): rational product x Mertens on [X0, s-H] x (1-2/s)^{-(2H+1)}.
   - The bottoms then telescope, and the early block plus the tail cancel the last carried factor.
   - Per row the result is <= e^gamma log(2z+H)(1+1e-8) <= A_R e^{2.2/Lambda}, so A_R is unchanged.
   Context: the E2E verdict (v3 2983) left the Staged Volume Lemma (SVL) "conditional on B §20". A self-contained paper needs this paragraph.
