# New arguments introduced while removing native_decide (for Appendix B)

## 1. Sparse r_low table: the jump lemma (replaces the dense r_low table of bs_cert / aux_cert)

Used by `RequestProject/BSCert/FX/Dickman.lean` (`jump`, `pairOK`), table in `FX/RTab.lean`, certified in `FX/RTabCert.lean`.

**Setting.** r = Dickman ratio, with (R2) r non-decreasing on [1,∞), r ≥ 1 there, and (R3) r(v) ≥ g(r(v−1)) for v ≥ 3, where g(t) = t/(1−e^{−t}) = t + φ(t) and φ(t) = t/(e^t − 1).

**Lemma A (φ is non-increasing on (0,∞)).** For 0 < s ≤ t: t/(e^t−1) ≤ s/(e^s−1).
*Proof.* Convexity of exp between 0 and t gives e^s ≤ (s/t)e^t + (1−s/t), i.e. e^s − 1 ≤ (s/t)(e^t − 1). Rearrange.

**Lemma B (jump).** Let x ≥ 2, 1 ≤ a ≤ r(x), A > 0, j ∈ ℕ, with A − a ≤ j·φ(A). Then A ≤ r(x+j).
*Proof.* Induction on i ≤ j: min(A, a + iφ(A)) ≤ r(x+i). For i = 0 this holds since a ≤ r(x). Step: put s = r(x+i) ≥ 1. (R3) gives r(x+i+1) ≥ s + φ(s).
- If s ≥ A, then r(x+i+1) ≥ s ≥ A.
- If s < A, then s ≥ a + iφ(A) (because the min is below s < A), and φ(s) ≥ φ(A) by Lemma A. So r(x+i+1) ≥ a + (i+1)φ(A).

At i = j the min equals A by hypothesis. ∎

**Single step (j = 1, used for n ≤ 1000).** If 1 ≤ a ≤ r(n), then r(n+1) ≥ g(r(n)) ≥ g(a) (g is non-decreasing: existing lemma `div_one_sub_exp_neg_mono`). And g(a) = a e^a/(e^a−1) ≥ aE/(E−1) for any E ≥ e^a > 1.

**Certificate.** Entries (n_k, a_k): every integer 2 ≤ n ≤ 1000, then n_{k+1} = ⌈1.003·n_k⌉ (plus 15810, 31620, 399999) up to 400001; 2949 entries. Checks, in fixed point with E an upper bound of e^{a_k} (single step) or of e^{a_{k+1}} (jump), computed by the verified FX exp:
- single step: a_{k+1}(E − 1) ≤ a_k·E;
- jump: (a_{k+1} − a_k)(E − 1) ≤ (n_{k+1} − n_k)·a_{k+1}.

First entry: a_0 ≤ lower bound of 1/(2(1 − log 2)) = r(2).

Lookup for u-cells: r(u) ≥ a_k for the largest n_k ≤ ⌊u⌋ (monotonicity).

**Loss against the exact recursion.** Using φ at the endpoint loses about j²φ|φ'| per jump; the numerical drift at n = 4·10⁵ is 0.0016 for ratio 1.003. The certified values are r(26) ≥ 4.5921, r(9) ≥ 3.2795, r(15810) ≥ 12.0598, r(31620) ≥ 12.8209, r(399999) ≥ 15.5711. These cover the claims used in the Beurling-Saias lemmas: 4.59, 2.19, 9, 12.82, 15.3.

## 2. Lemma 5.1(ii),(iii) for ℕ: shorter checked ranges (replaces finite_checks.py lines 2 and 6 in the proof of the corollary)

Files: `BSCert/Finite/CMWeak.lean`, `Beurling/Lemma51NatFull.lean` (`lemma_5_1_ii_nat_mid`), `Beurling/Lemma51NatBase.lean`.

**(ii) with K_M = 1.01, the paper's constant in Lemma 5.1(ii): −1.01 ≤ S(x) − log x ≤ 0.43 for all x ≥ 1.**
- For x ≤ 1000: direct kernel computation of S(N) = Σ_{n≤N} Λ(n)/n. The check at each N is S(N) − log N ≤ 0.43 and S(N) − log(N+1) ≥ −1.01.
- For x ≥ 1000: the Stirling argument already used above 10⁷, with the threshold lowered. From N S(N) − ψ(N) ≤ log N! ≤ N S(N), Stirling, and ψ(N) ≤ 1.42N:
  - S(N) ≥ log N − 1, and log x ≤ log N + 1/N, so S − log x ≥ −1 − 1/N ≥ −1.01 for N ≥ 100;
  - S(N) ≤ log N + 0.42 + (1 + (log N)/2)/N, and log N ≤ N/10⁴ + 10, so S ≤ log N + 0.43 for N ≥ 603.
- So the checked range shrinks from [1, 10⁷] to [1, 1000].
- The paper's sharper −0.753 ≤ S − log x ≤ 0 on [1, 10⁷] is kept (CMCertSharp), but the corollary does not use it.

**(iii) prime-power constant: Σ_p log p/(p(p−1)) ≤ 0.75539** (the paper has 0.75537; the true value is ≈ 0.7553666).
- 0.75539 suffices for the corollary: Lemma 5.1(iii) needs −1.01 − c ≥ −1.77, and GenLemma51Final.rest_le needs c + 6.8·10⁻⁷ ≤ 0.7554.
- Partial sum over p ≤ 10⁵: kernel-checked, ≤ 0.755357.
- Tail lemma: for N ≥ 2 and every M, Σ_{N<p≤M} log p/(p(p−1)) ≤ 1.42/N + 1.42/(N+1).
  *Proof.* Abel summation with a_k = log k·[k prime, k > N], w(k) = 1/(k(k−1)) non-increasing, and B(n) = 0 for n ≤ N, 1.42n otherwise. The bound Σ_{2≤k≤n} a_k ≤ B(n) holds by θ(n) ≤ ψ(n) ≤ 1.42n. Abel gives
  ≤ Σ_{n≥3} (B(n) − B(n−1)) w(n) = 1.42/N + 1.42 Σ_{n=N+2}^{M} 1/(n(n−1)) ≤ 1.42/N + 1.42/(N+1).
- Total ≤ 0.755357 + 2.84·10⁻⁵ ≤ 0.75539.
- This replaces the partial sum to 10⁷ with the tail (log N + 2)/N.

## 3. Region Z2 (cert_run_arb.py): adaptive covers in fixed point (replaces the uniform cover of Appendix B.1, region Z2)

Files: `BSCert/Z2K.lean`, `BSCert/Z2KChunks/K*.lean` (generated by `/tmp/rhscratch/gen/genz2.lean`), `BSCert/FX/*`.

The claim, the expression `z2Ex` and its exactness proof `z2Ex_eval` are unchanged: for ℓ ∈ [3·10⁹, 10¹⁸] and u ∈ [2, Ū(ℓ)], r(u−1) > γ₁, r(u−1) > γ_max and S(ℓ,u) > 0. What changes is how the (ℓ, u) region is split into cells. Soundness only needs every point of the region to lie in some accepted cell; every accepted cell is checked rigorously.

- **ℓ-bands.** Ratio 1.10 instead of 1.05 (7 bands per piece, 224 bands). Each piece ends exactly at the endpoints of the original 32 pieces.
- **Per band.** The split s = max(40, u₀(ℓ_a)/2) and the v-range [s − u₀, Ū − u₀] are computed as before, as enclosures over the whole band. The argument of `bandOK_sound` is unchanged: u ≤ s uses u-cells; u > s uses v = u − u₀(ℓ) ∈ [va, vb].
- **u-cells.** Top-level steps are +16 below 40 and ratio 2.6 above, each bisected up to depth 5. The script used steps +0.5 / ratio 1.05 with no bisection.
- **v-cells.** Width 32 × (the script's width). Bisected likewise.
- **Leaves.** The certificate lists only the accepted leaves of the bisection trees as explicit break points (`coverL`); the cells that failed and were bisected are not re-evaluated in the kernel.
- **Count.** 17,600 cell evaluations in total, against 301,000 for the script's cover.
- **Arithmetic.** Fixed point 2^-128 (`BSCert.FX`) instead of 64-bit rounded rationals. exp, log and sqrt have rigorous enclosures with Lean proofs, without floating-point hints.
- **r enclosure.** Upper bound unchanged ((R4) with δ chosen from fixed thresholds instead of a floating-point search). Lower bound from the sparse table of §1.

Nothing here is a new mathematical inequality: only the cell decomposition and the arithmetic differ from the script. A referee may want the script re-run with this decomposition.

## 4. Region X₀, n ≤ 10⁶ (x0band_exact.py): monotone reduction to 785 representatives (replaces the exhaustive loop of Appendix B.3)

Files: `BSCert/Finite/X0Mono.lean` (the reduction), `X0Formula.lean` (the integer formula), `X0Vec.lean` (exponent vectors and the H_ord certificate), `X0Rep.lean` (the representatives), `X0Chunks/X0C0–3.lean` (kernel checks), `X0BandCert.lean` (assembly). The statements `Bx_le_five_twelfths` and `Bx_six` are unchanged.

Notation: B(n) = (1/n)[μ²(n)/2 + (1/2) Σ_{d|n, 1<d<n} (2μ²(d) + (λ/2) X(d)/d)], with X(d) = Σ_{e|d, 1<e<d} μ²(e)·e·H(d/e), H = H_ord and λ = 1.0001.

**Lemma M (monotone representative).** Let n ≥ 2, with prime factors p₁ < … < p_k, and let q_i be the i-th prime. Define φ on the divisors of n by φ(∏ p_i^{a_i}) = ∏ q_i^{a_i}. Then B(n) ≤ B(φ(n)), with strict inequality if φ(n) < n.

*Proof.* φ is multiplicative, injective on divisors of n, preserves divisibility and the relation d < e for d | e, and fixes 1. Moreover q_i ≤ p_i, so φ(d) ≤ d.
1. μ²(d) = μ²(φ d): squarefreeness depends only on the exponents.
2. H(d) = H(φ d): H depends only on the divisor lattice, and φ is a lattice isomorphism from div(d) onto div(φ d). Only H(d) ≤ H(φ d) is used, proved by strong induction from H(m) = Σ_{d|m, d<m} H(d).
3. X(d)/d ≤ X(φ d)/φ(d). Write X(d)/d = Σ_{e|d, 1<e<d} μ²(e) H(d/e)/(d/e). Then term by term: μ²(e) ≤ μ²(φ e), H(d/e) ≤ H(φ(d)/φ(e)), and 1/(d/e) ≤ 1/φ(d/e), using φ(d/e) = φ(d)/φ(e). The index map e ↦ φ(e) is injective into the index set for φ(d), and the extra terms are ≥ 0.
4. Hence the bracket [·] of B(n) is ≤ the bracket of B(φ n): the same argument with d ↦ φ(d) over 1 < d < n. The prefactor satisfies 1/n ≤ 1/φ(n), strictly if φ(n) < n, and the bracket of B(φ n) is > 0 since φ(n) ≥ 2. ∎

**Lemma R (the representatives).** For 2 ≤ n ≤ 10⁶, φ(n) = 2^{a₁}3^{a₂}5^{a₃}7^{a₄}11^{a₅}13^{a₆}17^{a₇}, where the nonzero a_i form a prefix (a_i ≥ 1 exactly for i ≤ k) and k ≤ 7. The bound k ≤ 7 holds because a k ≥ 8 would give φ(n) ≥ 2·3·…·19 = 9699690 > 10⁶ ≥ n ≥ φ(n). There are 784 such numbers ≤ 10⁶ (785 vectors including 0), enumerated by `gen` (`mem_gen`).

**Lemma F (integer formula).** For m ≥ 1:
- 40000 m² B(m) = 20000 m μ²(m) + 40000 m c(m) + 10001 Q(m), where
- c(M) = Σ_{e|M, 1<e<M} μ²(e) and Q(m) = Σ_{f|m, f>1} H(f)(m/f) c(m/f).

*Proof.* The change of variables (d, e) ↦ (f, e) = (d/e, e) is a bijection from {e | d | m, 1<e<d, 1<d<m} onto {f | m, f>1, e | m/f, 1<e<m/f}. Under it μ²(e)·e·H(d/e)/d = μ²(e)H(f)/f, so Σ_{1<d<m} X(d)/d = Σ_{f>1} (H(f)/f) c(m/f) = Q(m)/m. Substitute. ∎

So B(m) < 5/12 ⟺ 3(20000 m μ²(m) + 40000 m c(m) + 10001 Q(m)) < 50000 m², an exact integer test.

**Evaluation on m = ∏ q_i^{v_i}.** Divisors are exponent vectors w ≤ v. Each term is computed from vectors:
- μ²(m_w) = [all w_i ≤ 1];
- c(m_x) = 2^{#{i : x_i > 0}} − 1 − [x ≠ 0 and μ²(m_x) = 1];
- m/m_w = m_{v−w}.

H is supplied as a certificate list (H(m_w))_{w≤v}. It is checked by the identity Σ_{u≤w} H(u) = 2H(w) for w ≠ 0, with H(0) = 1, which determines H by induction. The lattice zeta transform Σ_{u≤w} is computed one coordinate at a time with running block sums (`zeta`, proof `zeta_spec`). The cost is O(7·d(m)) per representative and Σ d(m) = 66618 in total.

**Result.**
- Maximum of B over the representatives other than 6: B(12) = 0.277780…
- B(6) = 5/12 exactly.
- Then for every 2 ≤ n ≤ 10⁶ with n ≠ 6, B(n) < 5/12:
  - either φ(n) < n (strict by Lemma M);
  - or φ(n) = n is a representative ≠ 6;
  - or φ(n) = 6 < n (strict by Lemma M).

This replaces the exhaustive evaluation of B(n) for all 10⁶ values of n by Lemma M plus 784 exact evaluations. A referee can check Lemma M independently (it is elementary). It is the only new mathematical ingredient; Lemma F is a reindexing.
